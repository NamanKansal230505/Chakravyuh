# ⚔️ Chakravyuh

A decentralized mesh of AI-powered sensor nodes built to *secure dense forests and harsh terrains* where traditional surveillance systems fall short.

🔗 *Live Project*: [chakravyuh-gamma.vercel.app](https://chakravyuh-gamma.vercel.app/)

## 🛡️ Overview

*Chakravyuh* is an autonomous security system that deploys a network of solar-powered, AI-enabled nodes to monitor sensitive areas in real time. Designed for military and wildlife applications, Chakravyuh combines *edge AI, **low-power networking, and **smart sensing* to create an invisible yet powerful safety net.

---

## 🚀 Features

* 🎯 *Real-Time Threat Detection*: Identifies critical sounds like footsteps, whispers, and gun reloads with low-latency response.
* 🌍 *Geo-Tagging & Timestamping*: Every event is precisely logged and mapped.
* ☀️ *Solar-Powered Nodes*: Operate independently with minimal maintenance.
* 📡 *Robust Connectivity*: Uses LoRa or NB-IoT for long-range, low-power communication.
* 🧠 *Edge AI Processing*: Local sound classification ensures quick decision-making without cloud dependency.
* 📊 *Centralized Dashboard*: Instantly view alerts, track activity, and assess threats in real time.

## 🏗️ Tech Stack

* *AI Models*: Edge-deployed sound classifiers
* *Hardware*: Microcontrollers with onboard sensors, LoRa/NB-IoT modules, solar panels
* *Backend*: Real-time alert system & event logging
* *Frontend*: Central dashboard for monitoring (Vercel hosted)
